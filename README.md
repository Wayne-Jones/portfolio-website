# Portfolio Website

Personal portfolio website for Wayne Jones — Software Engineer & Photographer based in New York, NY.

## Stack

- **Framework**: React 19 + TypeScript
- **Build**: Vite 8 + TanStack Start (SSR/SSG — static prerendering + client hydration)
- **Styling**: Tailwind CSS v4 + Base UI primitives
- **Fonts**: Self-hosted Inter Variable + Switzer (font-display: optional)
- **Lint/Format**: Oxlint + Oxfmt
- **Content**: Adapter pattern — Ghost CMS, committed snapshot JSON, mock fallback

## Routes

| Route | Description |
|-------|-------------|
| `/` | Homepage — hero, work portfolio, photography, recent posts, contact |
| `/blog` | Blog index with pagination |
| `/blog/:slug` | Individual blog post |
| `/photography` | Photography gallery (masonry) |
| `/portfolio` | Work portfolio index |
| `/portfolio/:slug` | Individual project case study |

## Getting Started

```bash
# Install dependencies
pnpm install

# Development server (mock content)
pnpm dev

# Development server against the live Ghost CMS
# Requires a local, git-ignored `.env.ghost.local` (VITE_CMS=ghost + Ghost
# Content API vars); `vite --mode ghost` loads it.
pnpm dev:ghost

# Refresh the committed content snapshot from Ghost
pnpm snapshot

# Production build + static prerender (runs the snapshot first)
pnpm build

# Preview the built static site
pnpm preview

# Lint
pnpm lint

# Format
pnpm format
```

## Motion System

- **Scroll Reveal**: `[data-reveal]` elements fade/slide up on 15% visibility (IntersectionObserver)
- **Hero Entrance**: Staggered fade+slide (intro → headline → location → portrait)
- **Parallax**: Hero portrait parallax on scroll (desktop only, rAF)
- **Shimmer**: Skeleton loading animation (`.animate-shimmer`)
- **Reduced Motion**: All animations disabled via `@media (prefers-reduced-motion: reduce)`

## Fonts

Self-hosted with `font-display: optional` to avoid CLS:

## Content Adapter & Static Snapshot

The content layer uses a strategy pattern:

```typescript
// src/content/index.ts
export const contentService = createContentService()
```

- `GhostAdapter` — live Ghost Content API (`VITE_CMS=ghost`)
- `StaticAdapter` — committed snapshot JSON in `src/content/data/` (production builds)
- `MockAdapter` — in-repo placeholder data (development default)

Selection:
- `VITE_CMS=ghost` → Ghost
- `VITE_CMS=snapshot` → StaticAdapter anywhere
- unset → `MockAdapter` in dev, `StaticAdapter` in production builds

### Snapshot workflow

The site is statically prerendered from a committed content snapshot so the
build needs no runtime access to Ghost.

1. `pnpm snapshot` fetches all posts/projects/photo sets from Ghost (when
   `VITE_GHOST_URL` + `VITE_GHOST_CONTENT_API_KEY` are set) and writes
   `src/content/data/{posts,projects,photosets}.json`. Without those env vars it
   falls back to mock data.
2. The snapshot is committed to git — rebuilds are deterministic and offline.
3. `pnpm build` runs the snapshot automatically (`prebuild`), so a fresh Deploy
   always gets the latest published content.

### Ghost → Vercel deploy hook

To auto-rebuild when content changes in Ghost:

1. In Vercel → project → Settings → Git → **Deploy Hooks**, create a hook and
   copy the URL.
2. In Ghost admin → Settings → **Integrations → Custom webhook**, create a
   webhook pointing at the Vercel hook URL for the events `post.published`,
   `post.updated`, `post.unpublished`, and `site.changed` (do not send the
   default full payload — Vercel's deploy hook only accepts the token URL).

Vercel rebuilds, the `prebuild` snapshot refreshes content, and the new static
site deploys automatically.

## Performance Optimization

### Image & Asset Management

- **Photo Gallery**: Images are loaded asynchronously with lazy-loading for performance. Ensure your photo sets use WebP/AVIF format with fallback JPEG.
- **Lazy Loading**: Below-fold images benefit from native `loading="lazy"` or intersection-observer implementation on demand.

## Deployment

- Client output: `dist/client/` — one `index.html` per route
  (`/`, `/blog`, `/blog/<slug>/`, `/portfolio/<slug>/`, etc.)
- Server output: `dist/server/` (SSR bundle — optional to deploy)
- Router uses `trailingSlash: "never"`; prerender writes subfolder `index.html`
  files (`autoSubfolderIndex`).

### Vercel

`vercel.json` configures the build for Vercel:

```json
{
  "outputDirectory": "dist/client",
  "cleanUrls": true,
  "trailingSlash": false,
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
}
```

- Serving directory is `dist/client/`.
- `cleanUrls` strips `.html` and `trailingSlash: false` normalizes trailing
  slashes on the static files.
- The catch-all rewrite hands unmatched URLs to the root document, where the
  `src/routes/$.tsx` splat route renders the not-found UI (TanStack Router's
  default not-found is not static-host-safe).

Any static host works — the same `dist/client/` directory can be served
wherever files are static (Netlify reads `netlify.toml`/`_redirects` instead of
`vercel.json`).

```bash
pnpm build  # produces dist/client/ (static) + dist/server/
```
